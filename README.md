# Portfolio — Jsssun

Personal portfolio website showcasing projects, experience, and skills.
Designed to clearly present my work as a CS student with interests in full-stack development, SAP, and game development.

## Live Demo
🔗 https://jsssun.github.io/portfolio/

## Overview
This portfolio focuses on clarity and usability rather than heavy frameworks.
It highlights selected projects with concise descriptions, roles, and tech stacks,
allowing visitors to quickly understand what I build and how I approach problems.

## Features
- Project-focused layout with detailed project views
- Dark / Light theme toggle (persisted with localStorage)
- Smooth scroll-based reveal animations
- Responsive design with custom scrollbar styling

## Tech Stack
- **HTML5**
- **CSS3** (CSS Variables, modern layout, color-scheme)
- **Vanilla JavaScript** (DOM control, state handling)
- **GitHub Pages** (deployment)

## Notes
This site is intentionally built without frameworks to demonstrate a solid understanding of
core web technologies and UI logic.
